# 📝 ToDo List — TP2 ENASTIC

Mini application To-Do List réalisée dans le cadre du TP2 de la matière **Outils et Méthodes de Développement** (L2-S3, DAWM).

## Fonctionnalités

- ✅ Ajouter une tâche (bouton ou touche Entrée)
- 🗑️ Supprimer une tâche
- ☑️ Marquer une tâche comme terminée
- 🔍 Filtrer : Toutes / En cours / Terminées
- 🧹 Supprimer toutes les tâches terminées

## Structure du projet

```
todo-team-project/
├── index.html   → Structure HTML (Étudiant A)
├── style.css    → Mise en forme CSS (Étudiant B)
├── script.js    → Logique JavaScript (Étudiant C)
└── README.md
```

## Technologies utilisées

- HTML5
- CSS3 (Responsive)
- JavaScript (Vanilla)

## Comment lancer le projet

Ouvrir `index.html` dans un navigateur web.
